# Native provider execution evidence

HOK-3495 carries provider facts from native requests and owned transcript turns through local eval/reliability records, the owning `@hokusai/core` contribution contract, and canonical Hokusai ingestion. It supplies evidence for endpoint qualification and provider selection in HOK-3496/HOK-3497; it does not change production routing restrictions or model/executor selection.

`nativeProviderExecutions` retains one observation per owned native response, including failed attempts. Records contain the runtime session, every recorded ownership attempt ID, response ID or stable observation ID, transport, requested and response models, request-time restrictions, scoped pricing snapshots, null-preserving usage, and observed OpenRouter generation metadata. Repeated response copies are deduplicated by the same observation projection used for SDK billing. Incomplete re-enrichment preserves known charges, models, rates and usage.

Requested restrictions are intent. `generation.providerName` is an upstream display name returned by the existing generation API client. Neither a model vendor prefix nor the `openrouter` transport establishes that host; display names do not prove region, service tier, deployment revision or quantization. These facts remain unknown when upstream evidence cannot establish them. Lookup is best effort and bounded by the existing client, and cannot fail a completed task.

A billed zero remains zero; absent billing is null. `@hokusai/costs` remains Wavemill's sole arithmetic/reduction authority. Native live-budget accounting uses the existing pricing adapter and resolved configured model rates, also captured as `scope: model`. Endpoint-specific snapshots use `scope: endpoint` only when supplied as endpoint evidence; model reference rates must not masquerade as endpoint rates. No new per-token formula or retry/budget policy is added.

`readLaunchHistory` preserves distinct launches after pending-ref resolution, while `getSdkMeteringProjection` bills a reused legacy session once. Compatibility ownership readers retain their existing session projection for control callers. Ambiguous reused sessions list their recorded attempts without inventing per-attempt allocation. This is the canonical data seam needed from HOK-3447; that issue still owns removal of session-based control identity, and HOK-3476 owns full task-attempt lineage adoption.

The termination recorder meters once before recording failure feedback, even when submission is disabled. Both local reliability and eval records retain cost/provider evidence. The existing reliability builder supplies fault attribution, including typed exit evidence. Verified terminal feedback now exports provider/harness/unknown failures as well as model failures. The canonical stage carries its fault class, and ingestion leaves model success unknown for non-model faults. Existing circuit eligibility remains separate from Hokusai model-quality labels.

Contributions use the SDK's optional `stage_executions[].provider_executions` and `failure`, never a private Wavemill wire schema. Session/launch/response identities are pseudonymized; session IDs pass through the same SDK identifier mapping as task-cost summaries. Strict validators reject extra/private metadata, duplicate observations and observations outside stage sessions. Challenger archive reads reuse `evalTaskStateKey`, so a shared Linear ID cannot discard the challenger arm's ownership. The existing inference-log join and route-override record link outcomes to routing decisions.

Canonical ingestion preserves reported charges before estimates. Mixed billed/unbilled observations retain a billed lower bound, billing coverage, trust and cost basis; endpoint estimates use the existing ingestion pricing primitives. Incomplete evidence cannot establish a full total. Charges remain `contributor_reported` evidence, not independently verified invoices. Historical records without provider fields retain their existing behavior.

Rollout order: SDK contract, compatible pipeline ingestion, then Wavemill producer. `vendor/README.md` pins the owning SDK commit and built artifact so a clean install works before an npm release. Replace that artifact with the published SDK minor release when available. No deployment or npm publication is implied by these PRs.

Tests include reconstructed generation evidence (explicitly labeled), failed/successful attempts, reused sessions, idempotent enrichment, billing-pending and billed-zero cases, request snapshots, terminal feedback, and one shared producer/redactor/SDK-builder wire replay consumed by pipeline tests. The native-arm golden journey covers failure recovery, settlement and canonical export with the existing shared fakes.
