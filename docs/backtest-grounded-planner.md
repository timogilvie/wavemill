- **The LLM judge trades recall for precision.** It removed 5 of the 11 deterministic false positives (precision 67.6% → 73.9%) but also cleared 6 true overlaps, mostly `wavemill-monitor.sh` pairs it judged to be in "different areas". In a 15k-line hot file, different areas still collide often. Tuning options for a follow-up: always treat `hot_file` overlap as `conflict` unless `disjoint_regions` fired, or drop the prompt's "disjoint regions are usually independent" guidance.
- **Remaining misses** (e.g. HOK-3107/HOK-3108 on `tend-controller.ts`) are tasks whose issue text names neither the file nor a function defined in it. The touch-set LLM prediction only runs for fully vague tasks, so it does not cover them.
- **Caveats.** Linear descriptions are read as they are today, not as they were at launch. Touch sets and co-change history use the commit before the window opened, so a task never "finds" a file its own PR created. Ground truth is file-level overlap; it does not prove a merge conflict happened.
