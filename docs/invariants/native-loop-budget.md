# Native loop budget

`native-agent/loop.ts` / `native-agent/tools/git.ts` / `wavemill_iso8601_to_epoch` — Native coding uses the shared loop budget (200 turns, 1,200 admitted tool calls, 60 minutes of model time (`maxModelTimeMs`; the clock pauses while a harness tool executes, so this is not a harness deadline — see `native-harness-deadlines.md`), shared stagnation thresholds). Entire tool batches, including invalid calls, are admitted before dispatch. Patch pre/post statistics use Git numstat before the crash-atomic write; private LCS tables are forbidden. Coding age checks use the shared ISO parser so native millisecond timestamps reach recovery. **One task spend limit (HOK-3492):** every production `runWavemillLoop` launch supplies `LoopBudget.maxCostUsd` from `resolveTaskSpendRemainder` (`shared/lib/task-spend.ts`) — the recorded task budget (`budget-source.ts`) minus the spend `meterWorkflowCost` measures over the task's owned sessions. A stop is the existing `budget_exhausted` fact with kind `cost`; it is terminal under `failure-policy.ts` (`task-budget-exhausted`) so no relaunch spends a bounded-retry attempt. Never launch a native loop without that limit, and never treat unknown metering as `$0` spend. Enforced by `tools/check-stage-exit-identity.ts` (`missing-task-spend-limit`); replay coverage includes a 24k-line patch under a 64 MiB heap, oversized tool batches and the agent-killed-mid-stage golden journey (HOK-3330), plus the cost-budget exhaustion journey (HOK-3492).
