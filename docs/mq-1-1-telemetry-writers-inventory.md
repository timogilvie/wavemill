### 1.3 Row schema (ten columns)

| # | Column | Content |
|---|---|---|
| 1 | **Writer** | Repo-relative `file:function` (or jq filter in a shell helper) |
| 2 | **Artifact** | On-disk path or logical sink |
| 3 | **Fields** | Top-level fields this writer sets (nested only when the nested path is the write boundary) |
| 4 | **Identity keys** | `task_id`, `pr_number`, `head_sha`, `branch`, `(state_dir, bucket, head)`, `session_id`, `(remote, ref, oid)`, etc. |
| 5 | **Consumers** | Primary readers (names, not every call site) |
| 6 | **Intent-vs-exec** | `intent-only` / `exec-only` / `mixed` / `n/a` |
| 7 | **Derived-as-primary** | `yes` / `no` — is a derived value stored as if primary? |
| 8 | **Actor** | `agent` / `monitor` / `tend` / `operator` / `controller` / `observer` / `native-loop` / `hokusai-cli` (maps to the HOK-3101 hook `writer` convention) |
| 9 | **Missing-vs-zero** | `missing!=zero` / `zero=default` / `null-ok` / `undefined-ok` |
| 10 | **Flags & gotchas** | HOK ref, condition-expiry triggers, duplicate-of, bounded-retry bucket, schema ref |

### 1.4 Judgement calls encoded in the row

- A function that reads an artifact and then writes a *derived* marker is counted once, in the writer position; the write is what we inventory.
- A function that only observes (`findCachedPullRequest`) is **not** a writer. The cache file is a `read-cache` row flagged under column 10, with no fields column.
- A test harness is **not** a writer unless it mutates production artifacts (none should).
- `wavemill-incident-store.ts` is a writer; its reader `incident-filing-reconciler.ts` is not.

### 1.5 The seven axes

1. **Lifecycle & workflow-state** — `.wavemill/workflow-state.json` task records (HOK-3220 schema), lifecycle schema, terminal reconciler tombstones.
2. **Stage results & execution economics** — `stage-result.*`, `session-ownership.*`, `execution-economics.*`, `workflow-cost.ts`, `sdk-task-cost/*`, pricing overrides, native-agent cost evidence.
3. **Queue, tend & merge lane** — `tend-*`, `merge-labels.ts`, `merge-queue.ts`, `tend-attempt-fact.ts`, revert guard, `pr-state-labels.ts`, merge-status comments.
4. **PR / check polling & Ready** — `ready-*`, `pr-ci-status.ts`, `ready-watchdog.ts`, `ready-remediation-disposition.ts`, `github-ci-discovery.ts`, `session-gh-cache.ts`, challenge-ready evidence.
5. **Retry, recovery & reconciliation** — `bounded-retry.{ts,sh}`, `condition-reconciler.sh`, `terminal-reconciler.sh`, `state-invariants.ts`, `reconciliation-context.*`, observer auto-fix buckets, challenge pair/stage recovery, failure-policy classifier.
6. **Observer, Backstage, incidents** — `observer-*`, `wavemill-incident-*`, `incident-filing-reconciler.ts`, `incident-linear-retry-queue.ts`, Backstage heartbeats, observer findings sink.
7. **Hokusai submission & contributions** — `hokusai-adapter.ts`, `hokusai-contribution-*`, `hokusai-queue*`, `hokusai-reward-ledger*`, `hokusai-router*`, `hokusai-trigger-log.ts`, cost/eval pool repair, parity/no-comparison reports.

Each writer row lives in exactly one axis (its primary residence); cross-cutting writers get a one-line pointer from the other axis.
