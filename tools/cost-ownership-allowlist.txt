# cost-ownership-allowlist.txt — authorized consumers of the Wavemill cost
# primitives (HOK-3077 guard, tools/check-cost-ownership.ts).
#
# Format (tools/lib/source-guard.ts): `<repo-relative path> [<count>]  # <reason>`.
# Every entry needs a same-line `# reason`. Counts are findings per file, so a
# listed file that adds a second primitive import, a retired engine call, or a
# private price formula still fails. The list is a ratchet: an entry that
# over-allows fails until it is lowered or removed. The primitives themselves
# (pricing/model-pricing.ts, pricing/openrouter-exact-pricing.ts,
# wavemill-session-paths.ts) and the guard spec are excluded automatically.
#
# A new consumer of *workflow cost* does not belong here: it reads the
# @hokusai/costs report through sdk-task-cost/meter.ts (live) or
# sdk-task-cost/recompute.ts (backfill), or the persisted WorkflowCost* shape
# (workflow-cost.ts). Classifications mirror
# shared/fixtures/cost-parity/consumer-inventory.json.
