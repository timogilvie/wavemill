# agent-background-work-allowlist.txt — justified exceptions to the one background-work decision guard (HOK-3374, tools/check-agent-background-work.ts).
#
# Format (tools/lib/source-guard.ts): `<repo-relative path> [<count>]  # <reason>`.
# Every entry needs a same-line `# reason`. Without a count the file is exempt
# entirely; with a count the file is still scanned and fails once it has more
# findings than that, so a new site in a listed file still fires. The list is a
# ratchet: an entry that over-allows (fewer findings than its count, none, or a
# missing file) fails until it is lowered or removed. The invariant source and
# the guard itself are excluded automatically and must NOT be listed here.
#
# Intentionally empty on first commit: the one background-work decision
# (deriveAgentBackgroundWork) must satisfy the ownership-only rule — a process
# is the agent's work iff it is a descendant of the agent that started after
# it — and the deleted HOK-3222 command-name classifiers must not reappear.
#
# Prefer a one-line `// allow-agent-background-work: <reason>` (`#` in shell)
# suppression over an entry whenever only a line or two is involved.
