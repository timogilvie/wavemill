# HOK-3235 — Preflight guard baseline for `WAVEMILL_*` env tokens.
#
# One entry per line: `WAVEMILL_NAME  # reason`. A trailing `*` or `_` makes
# the entry a dynamic prefix (matches `WAVEMILL_NAME_FOO`, etc.).
#
# This file is for *permanent plumbing* tokens: mill session/task identity,
# path and config env vars, loader-sourced guards, runtime constants, and
# runtime-built names from a fixed prefix. Short-lived flags, kill switches,
# rollbacks and shadow-mode switches go in `docs/feature-flags.md` instead,
# with an owner issue, a removal issue and a remove-by date.
#
# The preflight guard rejects any name here that matches the kill-switch
# pattern `(^|_)(DISABLED?|SKIP|SYNC|LIVE|SHADOW|LEGACY|AUTOFIX|ENABLED|FORCE|NO)(_|$)`.
#
# The baseline *only shrinks*: an entry whose name no longer appears in code
# must be deleted in the same change (ratchet, HOK-3235).
